# 使用前必看

1.运行后如果没有行动，或无法正常行动，运行 其他工具 里的 ==检测边境== 功能，再进游戏调节UI大小，直到游戏把滑动范围都包裹进去
2.建议关闭 保存调试图像 功能(如果你想内存膨胀的话，就开着)
