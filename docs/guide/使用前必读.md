# 使用前必看

1. 如果UI大小不匹配、MHD会识别失败、运行 其他工具 里的 检测边境 功能，再进游戏调节UI大小，直到游戏画面把滑动范围都包裹进去(仅手机版)

2. 还是解决不了的进群问吧

3. 请勿下载仓库以外的安装包、可能携带病毒等风险文件
